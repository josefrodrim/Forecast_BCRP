# notebooks

code that proves useful migrates to `pipeline/src/fxcast/` with tests.

| Notebook | Topic |
|---|---|
| `01_api` | Understanding the BCRP API |
| `02_eda` | Stationarity, autocorrelation, volatility, regimes |
| `03_baselines` | Random walk, drift, moving average + backtesting |
| `04_statistical` | ARIMA, ETS, Theta, GARCH |
| `05_ml_dl` | LightGBM, LSTM, GRU, CNN-LSTM |
