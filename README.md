# PEN/USD Forecast Arena

Forecasting the PEN/USD exchange rate with real data from the Central Reserve Bank of Peru (BCRP),
comparing models from naive baselines and ARIMA to CNN-LSTM — with a daily automated pipeline
and a live leaderboard.

> **Status:** work in progress (Phase 0 — setup).
>
> Educational project, not financial advice.
